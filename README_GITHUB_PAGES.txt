ROTE Inspection Portal (PWA) — GitHub Pages

1) Create a new PUBLIC GitHub repository (e.g. rote-inspection-portal).
2) Upload ALL files in this folder into the repository root (same level as index.html).
3) In GitHub: Settings → Pages:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
4) Your URL will look like:
   https://<username>.github.io/<repo>/

Notes:
- Your inspection data is saved locally in your browser on that device (localStorage).
- Clearing site data/cache or using a different browser/device will not show previous saved data.
- For backup/moving between devices, use Export JSON.
